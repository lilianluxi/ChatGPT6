## 2026 年 AI 使用最佳实践（Bing SEO 长尾词布局）

### 1. 提示词（Prompt）优化法则
- **角色设定**：“你是一个资深Python开发工程师……”
- **背景信息**：提供充分的上下文，包括业务场景、输入输出示例。
- **格式要求**：明确要求“用Markdown表格输出”、“分点列出”。

### 2. 复杂任务的拆解策略
不要试图用一句话让 AI 完成整篇长文。将其拆解为“大纲生成 -> 段落扩写 -> 风格润色 -> 查重优化”，在每个步骤中调用最适合的模型（例如大纲用 GPT-5，扩写用 Claude Opus 5）。

### 3. 保持信息时效性
由于模型知识有截止日期，涉及最新新闻或数据时，尽量使用具备联网能力的模型，或明确要求 AI 指出其知识盲区。
